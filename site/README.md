# Ask Eve site

Static site for https://askevepodcast.com, generated by `scripts/build_site.py` (stdlib only) from D1 plus the
transcripts in `episodes/` and `index/people.md`. `.github/workflows/site.yml` builds it into `site/dist` and
deploys it to Cloudflare Pages on every push to `main` that touches the site.

```
python3 scripts/build_site.py                                  # pull D1 (needs CLOUDFLARE_ACCOUNT_ID, D1_DATABASE_ID, D1_READ_TOKEN)
python3 scripts/build_site.py --db local.sqlite --include-drafts --out /tmp/dist   # from a local copy
cd /tmp/dist && python3 -m http.server 8000
```

Pages: `/` (latest episode hero, episode cards, subscribe), `/episodes/<slug>/` (player, chapters, synced
transcript, voice badges, people), `/episodes/<slug>/transcript.txt`, `/people/` and `/people/<slug>/`, `/about/`,
`/feed.xml` (rendered by `render_feed.py`, unchanged format), `sitemap.xml`, `404.html`.

Layout:

- `site/static/` copied into the build as-is. Files under `assets/` get content-hashed names (cached forever).
  - `assets/site.css`, `assets/theme.js` (applies the saved theme before paint), `assets/player.js` (player,
    transcript sync, theme toggle). No frameworks, no third-party requests, no analytics.
  - `fonts/fraunces-var.woff2`: Fraunces (SIL OFL, license alongside), Latin subset, used for headings. Body text
    uses the system font.
  - `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`, `og/*.jpg` (social cards) and
    `art/cover-3000.jpg` (podcast cover) are rendered by `scripts/render_art.py` (dev-only, needs Playwright).
    Re-run it after publishing an episode to give that episode its own social card; otherwise it uses
    `og/default.jpg`.
- `site/site.json`: subscribe links (`spotify`, `apple_podcasts`; a button appears only once a URL is set) and
  fallback one-paragraph blurbs per episode slug, used when D1 `episodes.summary` is empty.
- `site/_headers`: Cloudflare Pages headers (CSP, caching, feed content type).

Player deep links: `/episodes/<slug>/#t=SECONDS`. Playback position and speed are remembered in localStorage.
